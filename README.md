# Portfólio de Gabriel Campos

Portfólio pessoal construído com **React** e **Vite**.

## Desenvolvimento

Requer Node.js 20 ou superior.

```bash
npm install
npm run dev
```

O servidor de desenvolvimento será exibido no terminal, normalmente em `http://localhost:5173`.

## Produção

```bash
npm run build
npm run preview
```

O build otimizado é gerado em `dist/`.
